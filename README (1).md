# Fault Log JSON Extractor

This project demonstrates the extraction of structured JSON data from unstructured engineering fault logs using a Large Language Model (LLM) through the Groq API.

## Model Used

Llama 3.3 70B Versatile

## Features

- Extracts structured information from unstructured fault logs
- Generates JSON output
- Validates JSON using Python
- Saves extracted data to output.json

## Technologies

- Python
- Groq API
- OpenAI SDK
- python-dotenv

## Requirements

Install the required libraries:

    pip install openai python-dotenv

## Run

    python "FAI&PE_Experiment_02.py"
